# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-05-08

### Added
- **Modern Web Architecture**: Migración completa a React 18 (SPA).
- **GSAP Animations**: Transiciones premium y revelación secuencial de los resultados matemáticos.
- **Dynamic Math Engine**: Implementación de solver Gauss-Seidel en vanilla JavaScript puro (sin librerías externas), demostrando algoritmia raw.
- **Documentación ISO**: Creación de `SECURITY.md` y `QUALITY_POLICY.md` estandarizados.

### Changed
- El proyecto evolucionó de un repositorio estricto de VBA (Excel) a una aplicación web moderna orientada al portfolio de Data Science e Ingeniería de Software.
- Los archivos `.xlsm` originales fueron aislados en el directorio `/legacy_excel`.
